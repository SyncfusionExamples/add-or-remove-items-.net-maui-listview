# How to add or remove an item from .NET MAUI ListView(SfListView)?

The [.NET MAUI ListView (SfListView)](https://www.syncfusion.com/maui-controls/maui-listview) allows you to add or remove items by updating the collection bound to the [SfListView.ItemsSource](https://help.syncfusion.com/cr/maui/Syncfusion.Maui.ListView.SfListView.html#Syncfusion_Maui_ListView_SfListView_ItemsSource) from the  ViewModel.

**Steps**
1. Implement ViewModel with commands to bound to the view for adding or removing an item.
2. Define the AddCommand to add a new object to the collection of ViewModel.
3. Define the DeleteCommand to remove a object from the collection of ViewModel.

complete sample on [GitHub](https://github.com/SyncfusionExamples/add-or-remove-items-.net-maui-listview "https://github.com/SyncfusionExamples/add-or-remove-items-.net-maui-listview")
